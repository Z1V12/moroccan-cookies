# הקמת דאשבורד לידים — חינם לצמיתות

3 שלבים, כ-5 דקות. אני יכול לעשות את זה איתך צעד-צעד בדפדפן שלך אם תרצה —
רק תגיד "בוא נעשה את זה ביחד" ותהיה מחובר לחשבון Google שלך.

## שלב 1 — יצירת הגיליון

1. פתח [sheets.google.com](https://sheets.google.com) → גיליון חדש ריק.
2. שנה את שם הגיליון ל-"לידים - עוגיות מרוקאיות" (או כל שם שתרצה).

## שלב 2 — הדבקת הקוד

1. בתוך הגיליון: **תוספים ← Apps Script**.
2. מחק את מה שכתוב שם, והדבק את כל התוכן מהקובץ `apps-script.gs` (באותה תיקייה).
3. שמור (סמל הדיסקט או Ctrl+S). אפשר לשנות את שם הפרויקט למעלה אם רוצים.

## שלב 3 — פריסה כ-Web App

1. למעלה מימין: **Deploy ← New deployment**.
2. ליד "Select type" — לחץ על גלגל השיניים ובחר **Web app**.
3. הגדרות:
   - **Execute as:** Me (אתה)
   - **Who has access:** Anyone
4. **Deploy**. גוגל תבקש ממך לאשר הרשאות (Authorize access) — זה נורמלי,
   זו הרשאה של הסקריפט שלך לגיליון שלך, לא של אף אחד אחר. אשר.
5. תקבל **Web app URL** שנראה כך:
   `https://script.google.com/macros/s/AKfycb.../exec`
   **העתק את הכתובת הזו.**

## שלב 4 — הגנה על הנתונים שלך (חשוב, לא לדלג)

כתובת ה-Web App תופיע בקוד המקור הפומבי של האתר (כל אחד שיפתח "הצג מקור"
יוכל לראות אותה) — זה נכון לכל אתר סטטי שמדבר עם שירות חיצוני, לא ייחודי
לכלי הזה. כדי שלא כל אחד שידלה את הכתובת יוכל **לקרוא** את כל נתוני העסק
שלך (כמויות, מחירים, קצב לידים), נעל את הקריאה במפתח סודי:

1. ב-Apps Script: **Project Settings** (סמל גלגל השיניים בצד) ← **Script Properties**.
2. הוסף מאפיין בשם `DASHBOARD_KEY` וערך שרירותי משלך (מחרוזת אקראית וארוכה).
3. כשתדביק את הכתובת בדאשבורד, הוסף בסופה `?key=הערך-שלך`, למשל:
   `https://script.google.com/macros/s/AKfycb.../exec?key=abc123xyz`

**אל תוסיף את `?key=` לכתובת שנכנסת ל-`assets/data.js`** — שם צריך רק את
הכתובת הבסיסית, כי האתר רק *כותב* (doPost) ולא קורא, וזה לא דורש מפתח.

## שלב 5 — חיבור לאתר

פתח את `assets/data.js`, ומצא את השורה:
```js
leadsEndpoint: ""
```
והדבק את הכתובת הבסיסית בפנים (בלי `?key=`):
```js
leadsEndpoint: "https://script.google.com/macros/s/AKfycb.../exec"
```
העלה מחדש את `data.js` לגיטהאב — וזהו, האתר מתחיל לדווח לידים לגיליון.

## מה נכנס לגיליון

כל שיחה שמגיעה עד הצעת מחיר, וכל לחיצה על "המשך סגירה עם נציג" — עם סוג
אירוע, כמות אורחים, רמה, כמות בק"ג, מחיר, והאם הגיע ללקוח חם (לחץ וואטסאפ).
**לא נשמר שום פרט מזהה אישי** (לא שם, לא טלפון) — רק נתוני ההזמנה עצמה.

## חשוב לדעת

- זה חינמי לצמיתות בהיקף שימוש רגיל (Apps Script quota: 20,000 בקשות ביום).
- אתה הבעלים היחיד של הגיליון — אין לי ולאף אחד אחר גישה אליו.
- אפשר לכבות את זה בכל רגע: פשוט תרוקן את `leadsEndpoint` בחזרה לריק.
